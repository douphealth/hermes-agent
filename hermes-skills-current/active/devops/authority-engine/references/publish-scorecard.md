# Authority Engine Publish Scorecard

Score each item 0-2.
- 0 = weak / missing
- 1 = acceptable but not strong
- 2 = strong and competitive

## Technical
- indexability
- canonical / redirect health
- mobile usability
- obvious speed / CWV blockers

## Intent / Structure
- intent match
- page type match
- title / snippet strength
- answer-first intro
- heading stack quality

## Depth / Information Gain
- completeness vs SERP winners
- entity coverage
- examples / specificity
- useful tables / lists / steps
- originality / information gain

## AEO / GEO
- snippet readiness
- PAA coverage
- FAQ usefulness
- AI Overview extraction readiness
- self-contained citation-ready paragraphs

## Trust / E-E-A-T
- source quality
- author / editorial trust routing
- visible update / freshness signals
- trust-sensitive claims properly evidenced

## Internal Links / Conversion
- parent / hub link
- sibling support links
- trust links
- next-step CTA
- cluster contribution

## Score interpretation
- 28+ = enterprise-grade contender
- 22-27 = solid but still improvable
- 16-21 = publishable but not dominant
- under 16 = not ready for serious competition
