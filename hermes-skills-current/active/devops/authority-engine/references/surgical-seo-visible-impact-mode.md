# Surgical SEO Visible-Impact Mode

Use this reference when a surgical blog-post optimization needs to remain non-destructive but the user expects a major, obvious improvement rather than tiny polish.

## Trigger phrases

- "use the superpowers to the maximum extent"
- "10000x more powerful"
- "SOTA"
- "the changes are almost zero"
- "make it much stronger"
- "outperform competitors"

## Lesson

A surgical edit does not always mean a micro-edit. If the user asks for maximum force, the correct class-level behavior is an additive, evidence-based upgrade that visibly improves the article while preserving original intent, URLs, Yoast, author voice, and safe claims.

## Visible-impact checklist

Before publishing, ensure at least several of these are true:

- New H2/H3 sections appear in the live table of contents.
- The article gains real utility modules: tables, checklists, protocols, examples, templates, FAQ blocks, or decision frameworks.
- The top-of-page answer asset is stronger and extractable.
- Yoast title/meta/focus keyphrase better match the upgraded intent.
- Internal links reinforce the topical cluster.
- External references are repaired/cleaned and support trust-sensitive claims.
- Unsupported precise claims are removed or softened.
- Live read time/content length changes enough for a human reviewer to notice.

## Useful module types

- Body-weight or scenario-based target tables.
- Step-by-step decision system.
- Training-day or use-case templates.
- Before/during/after protocol table.
- Supplement or tool hierarchy.
- Red-flag checklist.
- Expanded FAQ/PAA section.
- Internal-link cluster paragraph.
- Source-backed reference block.

## Verification contract

Do not stop after API/XML-RPC success. Verify public/cache-busted output:

- title tag
- meta description count and text
- canonical
- exactly one H1
- new H2/H3 section(s) visible in body and TOC
- old bad strings removed
- no visible raw HTML/CSS leakage
- browser visual QA for tables and callouts when layout changed

## WordPress/GearUpToFit example pattern

For an athlete nutrition post, a stronger visible-impact upgrade added:

- `Athlete Nutrition Targets by Body Weight, Training Load, and Sport Type`
- macro targets by training demand
- 5-minute planning system
- training-day plate templates
- pre/during/post-workout fueling protocol
- supplement hierarchy
- red-flag checklist
- expanded athlete nutrition FAQ

This grew the live page read time and TOC, making the change obvious while still avoiding a full rewrite.
