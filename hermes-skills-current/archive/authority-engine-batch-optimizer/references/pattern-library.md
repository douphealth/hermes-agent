# Batch Pattern Library

## Pattern 1 — Quick Answer Lift
Use for pages already ranking or nearly useful.
- add query-aligned intent note near top
- add one snippet-ready answer block
- add related guides
- add next-step CTA

## Pattern 2 — Money Page Hardening
Use for commercial pages.
- tighten title/H1 alignment
- add trust/proof routing
- add gap section
- add FAQ/checklist/comparison block
- add dense contextual internal links

## Pattern 3 — Cluster Support Reinforcement
Use for support pages.
- clarify topical role
- link to hub and siblings
- add extraction asset
- improve intro and scannability

## Pattern 4 — Trust Routing Normalization
Use when trust assets exist but are weakly connected.
- identify canonical trust pages
- normalize links sitewide
- add visible trust note to important pages

## Pattern 5 — Duplicate Cleanup
Use when pages overlap.
- decide canonical winner
- convert weaker pages to support pages or deprioritize
- normalize internal links toward the winner
