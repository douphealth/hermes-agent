# Batch Opportunity Scorecard

Score each URL 0-5 on each dimension.

## Value
- commercial value
- lead-generation value
- brand/entity importance

## SEO Upside
- ranking potential
- snippet / PAA potential
- AI Overview / GEO citation potential
- freshness upside

## Leverage
- cluster leverage
- internal-link leverage
- trust-layer leverage

## Ease
- additive fixability
- content quality baseline
- implementation speed

## Risk / Drag
- duplication / cannibalization risk
- metadata/plugin blocker risk
- visual fragility risk

## Suggested formulas
### Priority score
(value + SEO upside + leverage + ease) - risk

### Queue guidance
- 16+ = immediate wave
- 12-15 = next wave
- 8-11 = useful but not urgent
- under 8 = low priority / cleanup / monitor
