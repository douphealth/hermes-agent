# Workflow Decision Tree

## If the user needs diagnosis first
Route to: site audit
Artifact: remediation plan

## If the user needs keyword/SERP clarity first
Route to: SERP lab
Artifact: brief / query ladder / page model

## If the user needs many pages prioritized
Route to: batch optimizer
Artifact: rollout waves and queue

## If the user needs live deployment now
Route to: WordPress execution
Artifact: live verification report

## If the user needs a full program
Sequence:
1. site audit
2. SERP lab
3. batch optimizer
4. execution

## Escalate when
- blockers are unclear
- multiple clusters compete for priority
- head/body split-brain appears
- archive scale makes manual choice wasteful
