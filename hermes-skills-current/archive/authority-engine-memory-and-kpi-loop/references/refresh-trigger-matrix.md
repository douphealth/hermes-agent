# Refresh Trigger Matrix

## Trigger: ranking drop
Default action: audit or SERP re-check depending on scale

## Trigger: CTR weak vs visibility
Default action: snippet/title/intro review

## Trigger: freshness age threshold crossed
Default action: refresh top sections, sources, dates, and internal links

## Trigger: new AIO/snippet opportunity
Default action: add extraction blocks and re-brief structure

## Trigger: new supporting pages published
Default action: internal-link reinforcement pass

## Trigger: trust-sensitive page still weak
Default action: trust-layer remediation and proof enrichment

## Trigger: duplicate/cannibalization signal
Default action: consolidation review
