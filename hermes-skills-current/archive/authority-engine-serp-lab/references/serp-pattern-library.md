# SERP Pattern Library

## Pattern 1 — Direct Definition SERP
Signal: definition pages, glossary pages, short answer blocks dominate.
Action: lead with a crisp 40-60 word definition and expand only after the answer lands.

## Pattern 2 — Comparison / Alternatives SERP
Signal: vs, alternatives, best-for, competitor roundups dominate.
Action: use comparison tables, pros/cons, fit-by-scenario, and decisive tradeoff language.

## Pattern 3 — How-To / Process SERP
Signal: ordered tutorials, checklists, step pages dominate.
Action: use ordered steps, mistakes, prerequisites, and troubleshooting sections.

## Pattern 4 — Hybrid Commercial-Informational SERP
Signal: guides plus commercial pages mix in top results.
Action: satisfy education first, then route into a clear next-step CTA.

## Pattern 5 — Snippet-Weak SERP
Signal: ranking pages exist but answers are bloated or buried.
Action: create cleaner extraction blocks and self-contained answer sections.

## Pattern 6 — AIO-Friendly SERP
Signal: broad informational query with multi-angle synthesis potential.
Action: cover benefits, risks, alternatives, timing, suitability, and concise evidence-backed summaries.
