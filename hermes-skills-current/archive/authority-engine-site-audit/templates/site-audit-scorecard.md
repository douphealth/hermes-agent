# Site Audit Scorecard

Score each important URL, cluster, or site section 0-2 per item.

## Technical
- indexability
- crawlability
- canonical / redirect health
- mobile usability
- speed / CWV risk

## Content / Intent
- page type fit
- answer-first structure
- depth / utility
- information gain
- extraction-ready formatting

## Authority / Links
- hub alignment
- sibling support
- inbound internal-link support
- trust-link visibility
- next-step routing

## Trust / E-E-A-T
- author / byline visibility
- trust-page routing
- source quality
- freshness / update signal
- entity clarity

## Metadata / Schema
- title/meta quality
- OG consistency
- schema relevance
- schema conflict risk
- plugin-layer blocker risk

## Priority guidance
- 24+ = strong section, maintain and refine
- 18-23 = solid but improvable
- 12-17 = underpowered
- under 12 = high remediation priority
