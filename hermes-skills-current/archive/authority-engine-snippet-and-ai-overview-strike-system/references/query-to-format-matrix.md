# Query-to-Format Matrix

## What is / who is / definition intent
Preferred format: 40-60 word definition paragraph

## How to / steps / process intent
Preferred format: ordered steps

## Best / types / ways intent
Preferred format: list with concise intros

## Compare / vs / alternatives / pricing intent
Preferred format: table + short summary paragraph

## Why / when / can / should intent
Preferred format: concise paragraph + bullets where useful

## Broad synthesis / AI Overview-prone intent
Preferred format: multi-angle structure with short answer summaries under each section
