# Strike Pattern Library

## Pattern 1 — Definition Strike
Use for glossary/definition queries.
Add a clean 40-60 word answer directly under the matching heading.

## Pattern 2 — Table Strike
Use for comparisons/cost/alternatives queries.
Add a concise comparison table with clear headers and short cells.

## Pattern 3 — Step Strike
Use for procedural queries.
Add ordered steps with action-led phrasing.

## Pattern 4 — PAA Net
Use when multiple adjacent questions can be won on one page.
Add tightly scoped subquestion headings and concise answers.

## Pattern 5 — AIO Summary Mesh
Use for broad informational queries.
Add short summaries under benefits, risks, alternatives, timing, and suitability sections.
