# Ranking & Visibility Playbook (2025–2026)

Use this reference when planning, rewriting, or publishing SEO content that must compete for #1 rankings, Featured Snippets, People Also Ask, AI Overviews, Bing Copilot, Perplexity, and LLM citations.

## 1. Technical SEO gates
Do not scale content onto a technically broken surface.

Critical targets:
- LCP < 2.5s
- INP < 200ms
- CLS < 0.1
- mobile-first responsive layout
- HTTPS everywhere
- crawlable critical resources
- current XML sitemap submitted to GSC and Bing
- self-referencing canonicals
- zero broken critical links / 5xx errors
- redirects capped at one hop
- TTFB < 800ms, ideally < 200ms with CDN
- optimized images: WebP/AVIF, lazy loading, srcset
- breadcrumb navigation + BreadcrumbList schema
- no orphan pages; all important pages reachable within 3 clicks
- log review or crawl review to confirm bots hit priority pages
- use IndexNow when available for fast discovery

If the user asks for content work and the page fails obvious technical gates, report that content gains may be capped until the technical blockers are fixed.

## 2. On-page SEO requirements for every page
Every serious page should define and verify:
- one primary keyword / query class
- dominant intent: informational, commercial, transactional, hybrid
- buyer stage
- page type that actually wins this SERP
- exact next-step conversion or continuation action

### Title / snippet layer
- primary keyword inside the first ~60 characters
- title length roughly 50–60 chars / within pixel limits
- include a strong differentiator: number, result, timeframe, or angle
- use current year only when it improves intent match and freshness
- unique title and meta per URL
- meta description should match intent and include value + CTA

### Heading / structure layer
- exactly one H1
- H2s should reflect secondary intents, PAA questions, comparisons, risks, benefits, alternatives, cost, mistakes, and process steps where relevant
- do not use generic filler headings like “Introduction” or “Conclusion” unless they are clearly useful
- for long pages, include a table of contents / jump links

### Body copy layer
- primary keyword naturally in first 100 words
- answer-first intro; do not bury the answer
- match or exceed the practical depth of top winners without filler
- short paragraphs, active voice, strong scannability
- use lists, tables, comparison blocks, steps, warnings, FAQs, and examples where they improve utility
- each major section should be substantive; avoid thin 2-sentence shells
- internal links: parent, sibling, next-step, and trust links
- external sources: primary studies, official docs, credible reference sources
- include descriptive alt text and useful images when visuals aid understanding

## 3. Topical authority model
Content should not be produced as isolated pages.

Required planning hierarchy:
- pillar / hub pages: head terms, 3000–5000 words when justified
- cluster pages: 1500–2500 words around long-tail or modifier intents
- subtopic / support pages: 800–1500 words for tightly scoped questions, definitions, objections, or troubleshooting

Authority rules:
- define the topical map before scaling output
- prefer full coverage of a smaller set of pillars over shallow coverage of many
- every page must fit a hub-and-spoke structure
- each page should receive at least 3 internal links from relevant pages
- link new content from existing authority pages fast
- keep a freshness program for top traffic / revenue pages every 90 days or faster in volatile niches
- track coverage %, internal link density, and SERP presence per pillar

## 4. AEO: featured snippets, PAA, voice, answer boxes
For answer extraction, every target section should follow:
1. question / intent heading
2. direct answer in the first 1–2 sentences
3. elaboration with specifics
4. optional list, steps, or table

Winning extraction patterns:
- definition snippets: 40–60 words directly below “What is …” headings
- paragraph snippets: concise answer block first, then expansion
- list snippets: 5–8 clean bullets or ordered items
- step snippets: ordered process with explicit steps
- table snippets: comparison / pricing / specs / pros-cons
- voice style answers: concise, natural, spoken phrasing
- FAQPage only when the page naturally contains real recurring questions
- SpeakableSpecification only when a site can support and benefit from it

## 5. GEO: generative engine optimization
AI systems prefer content that is easy to cite and trust.

Required GEO patterns:
- cite 3–10 authoritative sources when the topic needs evidence
- include specific statistics, dates, and sourced claims
- use decisive, well-supported language rather than hedging mush
- define entities cleanly on first mention
- make paragraphs self-contained so an extracted paragraph still makes sense
- use comparison tables, spec tables, cost tables, and ordered lists
- create quotable factual sentences and frameworks
- surface recency clearly: “Updated April 2026”, “As of 2026”, etc.
- answer the exact query under a matching heading before expanding
- cover adjacent angles AI Overviews often synthesize: benefits, risks, costs, alternatives, mistakes, timing, suitability

## 6. AI visibility / LLM citation layer
When the goal expands beyond rankings into brand recall or citation:
- maintain consistent entity information across About, author, organization, social, and directory profiles
- publish original data, frameworks, research, and case studies where possible
- encourage citations and mentions from authoritative external sites
- strengthen About, author, editorial policy, review methodology, contact, and trust pages
- create clean, self-contained definitions of the brand, product, person, and methodology
- monitor whether major LLMs and AI search products cite the brand or page type

## 7. E-E-A-T requirements
Trust-sensitive or competitive pages should include:
- visible byline and author context
- author page with credentials / experience / sameAs profiles where appropriate
- visible update date
- editorial policy / review methodology / disclosure routing
- first-hand experience, examples, original photos, tests, or process notes when available
- citations to primary sources, not just other blogs
- real contact and policy pages at site level

## 8. Internal linking / authority routing
Minimum internal-link system for a serious page:
- 1 parent / hub link
- 2 sibling or supporting links
- 1 next-step conversion or continuation link
- 1 trust or methodology link when appropriate

Anchor-text rules:
- mostly partial-match descriptive anchors
- limited exact match
- branded and generic anchors mixed in naturally
- route authority from strong pages into money pages, new pages, and under-linked pages

## 9. Measurement and optimization rhythm
Core KPIs:
- organic sessions
- keywords in top 3 / top 10
- CTR
- internal-link coverage
- topical coverage %
- referring domains
- Core Web Vitals pass rate
- Featured Snippet wins
- AI Overview citations
- AI brand mentions
- revenue or conversions per page
- freshness age for top pages

Suggested operating cadence:
- daily: check critical rankings and crawl issues for priority pages
- weekly: publish / update cluster pages and reinforce internal links
- bi-weekly: expand keyword + entity maps
- monthly: refresh top pages, review snippets/AIO, audit schema, acquire links
- quarterly: prune/merge thin content, reassess clusters, review trust layer, re-score authority

## 10. Priority execution order
1. technical blockers
2. topical map
3. pillar/hub pages
4. cluster pages
5. internal linking system
6. schema layer
7. AEO pass
8. GEO / AI citation pass
9. E-E-A-T hardening
10. off-page / link acquisition
11. KPI review and iteration

## 11. Content scoring rubric
Before publishing, score the page 0–2 for each:
- technical readiness
- intent match
- title/snippet strength
- answer-first intro
- structure / headings
- depth / completeness
- information gain vs competitors
- evidence / citations
- snippet readiness
- AI Overview readiness
- internal-link routing
- trust / E-E-A-T
- conversion next step
- freshness signal
- media / tables / visual aids

Do not call a page “enterprise-grade” unless it can credibly score strong across most categories.
