# WordPress Trust Blocks and Proof Elements

## Purpose
Increase perceived credibility and decision confidence with compact, useful trust modules.

## Principles
- Never fabricate proof.
- Founder-led honesty beats fake expert theater.
- Trust blocks should feel calm, specific, and useful.
- Add proof where the user actually needs reassurance: before decisions, comparisons, CTAs, and sensitive claims.

## Block types
- editorial note
- methodology note
- evidence note
- disclosure note
- reviewer/founder context block
- caution/warning box
- what this page does not claim block

## Placement rules
- near the top for high-stakes pages
- before strong claims or comparison tables
- near conversion actions when trust is needed
- not repeated so often that the page feels paranoid or legalistic

## Good outcomes
- users understand who wrote the page
- users know how recommendations were made
- users can find policy/methodology pages easily
- trust improves without making the page ugly

## Output contract
Report:
- trust blocks added
- where they were inserted
- what proof or methodology they convey
- whether anything remained blocked by missing real evidence
